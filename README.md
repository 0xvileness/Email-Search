Email Search check 120+ sites and finds possible data breaches.

Functions: 
Scans 120+ websites (social media, forums, e‑commerce, etc.)
Detects data breaches (e.g., Adobe, LinkedIn, etc.)
Saves results in JSON format inside records/ folder Secure – your API key is stored in .env (ignored by Git)
Written in Python – easy to modify and extend

Installation

pip install colorama
pip install holehe 

Steps: 

cd Email-Search
python3 email.py {email}
